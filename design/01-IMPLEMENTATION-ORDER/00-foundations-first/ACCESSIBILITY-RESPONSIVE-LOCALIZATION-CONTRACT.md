# Accessibility, Responsive & Localization Contract
Accessibility requirements include keyboard operation, visible focus, logical focus order,
skip/navigation mechanisms, semantic landmarks/headings, labels and descriptions, associated
validation errors, accessible tables/dialogs, screen-reader announcements, sufficient contrast,
reduced-motion support, and accessible interview/code-editor interactions.

Responsive implementation must test representative desktop, tablet and mobile widths and avoid
horizontal scrolling for ordinary content. Dense tables may use responsive cards, controlled
horizontal regions or alternate views where semantically appropriate.

Localization readiness includes locale-aware dates/times/timezones, numbers, currencies and salary
display, long-text resilience and layout readiness for future languages. Do not claim languages are
supported until translations and QA actually exist.
