# CareerScope Icon System

Use one consistent production icon system across the application. Do not mix unrelated icon families or regenerate icons per page.

Auth/loading references require, at minimum: email, lock, eye/show-hide password, Google mark, back arrow, forward arrow, check/success, warning, error, information, search/discover, layers/match, document/application, analytics/growth, shield/security, spinner/loading, clock/session.

Use semantic labels and accessible names for interactive icons. Decorative icons must be hidden from assistive technology.
