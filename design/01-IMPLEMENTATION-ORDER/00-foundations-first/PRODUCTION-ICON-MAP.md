# CareerScope Production Icon Map

## Rule
Use ONE consistent outline icon family for product UI. Do not redraw or mix icon families.
The generated reference screenshots are visual targets, but raster screenshots do not contain reusable vector icon source files.

Recommended implementation mapping: Lucide-compatible outline icons (or the existing project icon library if it already maps equivalently), using consistent stroke width, size, optical alignment, hover/focus treatment, and accessible labels.

## Brand/vendor marks
CareerScope logo/brandmark and third-party company/provider logos must NOT be approximated with generic icons.
Use official/approved assets where legally permitted. If a brand asset is unavailable, use a neutral company/avatar fallback rather than inventing a logo.

## Pixel-parity rule
For every icon in a canonical screenshot, match:
- semantic meaning
- approximate bounding box
- stroke weight
- baseline/optical alignment
- button/container dimensions
- active/inactive color token
- hover/focus/disabled states

Do not raster-crop tiny icons from screenshots for production.
