# CareerScope design source

This directory contains the approved visual source material for the single
CareerScope web product. It is reference-only; routes do not load screenshots
or design documents at runtime.

## Canonical references

- `canonical/` approved screens and states
- `brand/` logo and identity assets
- `foundations/` tokens, accessibility and responsive contracts
- `assets/` icons and supporting production assets
- `approved-images/` approved full boards and screenshots

`future-releases/`, `references/` and implementation notes are
preserved where they contain unique approved references, but they are not
runtime sources. The canonical visual language is the CareerScope navy,
blue-accent light SaaS system with responsive layouts and accessible focus
states. Do not invent a second logo or redesign approved screens without a
separate product decision.
